# Chile bajo la piel

Sitio editorial estático en español. HTML, CSS y JavaScript sin dependencias, compilación, cookies, analítica ni formularios que almacenen información.

## GitHub Pages

En Settings → Pages, seleccionar **Deploy from a branch**, rama `main`, carpeta `/ (root)`. Todas las rutas de recursos son relativas y funcionan bajo `/CHILE_BAJO_LA_PIEL/`. `.nojekyll` evita procesamiento innecesario. También puede servirse localmente con cualquier servidor estático.

## Contenido

La propuesta de investigación se distingue de resultados todavía no publicados. La cifra de 15–20 entrevistas expresa un objetivo metodológico. No se afirman adjudicación, entrevistas realizadas ni métricas. El estado administrativo queda pendiente de confirmación oficial; no se toma como comprobante la afirmación de postulación presentada de un caso de estudio anterior.

El contacto dirige al canal ya publicado de Diego Pazos. Las piezas exhibidas son obra previa del autor, no testimonios ni retratos de participantes. No se publica el PDF completo porque incluye información personal.

## Accesibilidad e interacción

HTML semántico, enlace de salto, navegación por teclado, foco visible, imágenes con alternativas, menú adaptable con estado anunciado, acordeones nativos y ampliación de obras mediante diálogo con Escape y retorno de foco. Sin JavaScript siguen disponibles el contenido, la navegación, los acordeones y los enlaces a imágenes. Se respeta `prefers-reduced-motion`.

## Mantenimiento

- Textos y enlaces: `index.html`.
- Diseño y tamaños: `css/styles.css`.
- Menú y visor: `js/main.js`.
- Recursos y su procedencia: `assets/` y `docs/procedencia.md`.
- Actualizar el estado de postulación únicamente con evidencia confirmada.

Las obras conservan los derechos de su autor; este repositorio no concede una licencia de reutilización de imágenes.
